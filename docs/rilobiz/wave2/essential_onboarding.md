# RiloBiz — Essential Onboarding
## Existing Business Owners

---

## Overview

Essential onboarding replaces the old two-stage flow (quick onboarding + 45-question full questionnaire). One flow, four phases, built from the highest-signal questions only — everything else moves to Wave 2+ (dynamic, AI-selected, drawn from the full 14-bucket + industry bucket question bank).

- **Phase 1** — Opening identifiers
- **Phase 2** — 21 core questions (9 operational, 12 diagnostic)
- **Phase 3** — Identifiers for AI research (Instagram, website) → AI fetches + generates confirmation card
- **Phase 4** — Closing identifiers (phone, email, location)
- **Phase 5** — One closing emotional question, transitions into the home page

Total user-facing questions: **28** (down from ~53 across the old quick + full flow).

Everything collected feeds the memory pool. Nothing is stored in the onboarding screen itself.
